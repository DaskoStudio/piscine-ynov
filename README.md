# Piscine Ynov — Exercices

Recueil des exercices de programmation (« piscines ») réalisés à **Ynov Campus**, regroupés par langage. Chaque dossier contient de nombreux exercices courts couvrant les bases (algorithmes, manipulation de chaînes, structures de données, POO…).

## 📂 Contenu

| Langage | Dossier | Contenu |
|---|---|---|
| **Go** | [`go/`](go/) | Fonctions, récursivité, chaînes, slices… |
| **JavaScript** | [`javascript/`](javascript/) | Manipulation de données, fonctions, logique |
| **Java** | [`java/`](java/) | POO (abstraction, interfaces, exceptions…) — projet « Adventure » |

## 🎯 Objectif

Montrer la **polyvalence** et la **régularité** : exercices fondamentaux travaillés dans trois langages.
