# Piscine Ynov — Exercices

Recueil des exercices de programmation (« piscines ») réalisés à **Ynov Campus**, regroupés par langage. Chaque dossier contient de nombreux exercices courts couvrant les bases (algorithmes, manipulation de chaînes, structures de données, POO…).

## 📂 Contenu

| Langage | Dossier | Contenu |
|---|---|---|
| **Go** | [`go/`](go/) | Fonctions, récursivité, chaînes, slices… |
| **JavaScript** | [`javascript/`](javascript/) | Manipulation de données, fonctions, logique |
| **Java** | [`java/`](java/) | POO (abstraction, interfaces, exceptions…) — projet « Adventure » |

## 🎯 Objectif

Montrer la **polyvalence** et la **régularité** : exercices fondamentaux travaillés dans trois langages.

## 👤 Auteur

Konaté Adama (**[@DaskoStudio](https://github.com/DaskoStudio)**) — Ynov Campus

## ✨ Fonctionnalités

Exercices indépendants regroupés par langage ; aucun service applicatif commun.

## 🧱 Structure

`go/`, `javascript/`, `java/` : exercices par langage.

## 🚀 Lancer

Installer le langage correspondant puis consulter l’exercice choisi : chaque exercice possède son propre point d’entrée ou ses fonctions. Pour Go, les dépendances du module s’installent avec `cd go && go mod download`. Les commandes de lancement dépendent de l’exercice ; il n’existe pas de commande globale pour ce recueil.

## 🛠️ Stack

Go · JavaScript · Java.
